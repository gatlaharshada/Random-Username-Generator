# 🔥 Random Username Generator

Welcome to the **Random Username Generator** project!  
This Python project generates unique, fun, and creative usernames by combining random adjectives and nouns — perfect for social media, gaming, and more!

---

## ✨ Features

- Combines random adjectives and nouns to create usernames
- Option to **include numbers** (e.g., CoolTiger123)
- Option to **include special characters** (e.g., HappyNinja99@)
- **Save** all generated usernames to a `usernames.txt` file
- **GUI version** using **Tkinter** for easy user interaction

---

## 🛠️ Tech Stack

- Python 3.x
- Tkinter (for GUI)
- `random` and `string` modules
